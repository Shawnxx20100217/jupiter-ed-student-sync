# 功能支持与限制

| 功能 | 当前边界 |
| --- | --- |
| 课程与教师 | 读取已配置完整课程范围内、页面实际提供的字段；不同学校页面差异可能导致安全停止 |
| 作业名称、分类、评分 | 保留 Jupiter 原始显示信息，不随机修改分数、不补造缺失字段 |
| GPA | 不提供官方 GPA，也不将自行计算的估值冒充学校结果 |
| 日期 | 保存原始文本；只有证据充分时增加推断字段，明确区分 raw 与 inferred；不擅自补年份或 23:59 |
| To Do 对照 | 使用当前已认证页面及数字作业 ID 对照；无法证明课程或身份覆盖时停止 |
| 学校 Calendar（可选） | 在同一会话里按月份读取。已核验日期的公告可组成当天摘要，供本地查看；仍需对照实际月份覆盖情况 |
| 增量检测 | 按学校、账号、学年、学期、课程及数字作业 ID 识别；不按相似标题合并 |
| 暂时消失的记录 | 保留历史并标记本次未观察到；不自动删除或判定完成 |
| 加密状态 | 私有仓库 `sync-state` 分支 `state.enc.json`；AES-256-GCM；写前校验、并发冲突检查、写后加密回读 |
| JSON 导出 | 只读解密到自己的本地私有目录；导出的明文仍属于个人学业数据 |
| TickTick | 仅本地 JSON 建议，不连接 TickTick、不读远端、不写入任何项目 |
| Cloudflare | 可选补采模板，独立部署；仅检查健康信息并调用同一 GitHub 读取器 |
| 告警提醒 | 未预启用自定义邮件或 Issue 告警；平台原生通知取决于账号设置 |
| 提交、Done、成绩修改 | 不支持，禁止此类写入 |
| AI 学习规划 | 不包含规划器，也不会自动发送数据给 AI 服务 |

## 记录和待办不是同一回事

Jupiter 的成绩列表可能含课堂测验、出勤、历史成绩和未评分记录。这些可以保存在原始数据内，但不能仅因出现在列表中就生成课外待办。已评分、已提交、私人 Done、TickTick 完成是不同状态；此模板不会互相推导。

日期只有月/日而无可靠年份证据时，保留未知；只知道某一天而不知道时间时，不能写成当天 23:59。时区来自该学生配置，不默认所有学校使用同一时区。

## 首次部署和运行的实际边界

纯合成测试验证规则和隔离行为，不证明新账户的真实页面兼容性。独立账户首次登录与真实课程读取仍待授权测试。验证码、双因素、学校访问控制需要本人正常处理，本工具不会绕过。

GitHub Runner 不依赖某台学生电脑保持开机，但 GitHub schedule 不保证精确时间。页面维护和网络故障会保留最后有效状态；较旧的数据不能宣称已更新。可选 Cloudflare 也不能保证上游学校服务器可用。

当前适配器只观察已经采集到的页面字段。不声称完整覆盖所有课程附件、教师评语、作业正文变化或所有 Jupiter 学校配置。发现解析差异时应停止该次保存并保留旧快照，不能悄悄漏课后仍标记完整成功。
